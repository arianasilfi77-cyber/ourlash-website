# PROJECT OBJECTIVES

The purpose of this website is NOT simply to display information.

It is designed to achieve five business goals.

## Goal 1

Build trust within the first few seconds.

"This brand looks professional."

Increase booking conversions from Instagram visitors.

- Instagram Bio
- WhatsApp Link
- QR Code
- Google Business Profile

Create a premium first impression.

Explain services clearly.

---

Increase long-term customer retention.

- Loyalty Card
- Welcome Offer
- Ramadan Appreciation

# NAVIGATION SYSTEM

## Primary Navigation

The navigation bar must remain minimal, elegant and distraction-free.

Navigation Items:

- Home
- About
- Services
- Programs
- Gallery
- FAQ
- Contact

Do NOT include dropdown menus.

Do NOT add unnecessary navigation links.

The website should remain intentionally simple.

---

## Navbar Behavior

The navigation bar should be sticky.

While at the top of the page:

- Background should be transparent.
- Blend naturally with the Hero section.

After scrolling approximately 50–80px:

- Apply a white background.
- Add subtle blur effect.
- Add a very soft bottom border.
- Keep the transition smooth (250–350ms).

The navbar should never feel heavy.

---

## Logo Placement

Desktop:

Top-left.

Top-left.

The logo should always remain visible.

Use generous spacing around the logo.

Never place decorative elements near it.

# MOTION & ANIMATION SYSTEM

## Philosophy

Motion should support usability rather than attract attention.

Every animation must feel calm, elegant and intentional.

The website should never feel flashy or playful.

Animations exist to guide the user's attention and create a polished experience.

---

## General Animation Rules

Animation duration:

- Fast: 200ms
- Standard: 300ms
- Slow: 500ms

Preferred easing:

ease-out

Avoid:

- Bounce
- Elastic
- Shake
- Flip
- Rotate
- Zoom explosion

---

## Page Load

Hero content fades upward sequentially:

1. Navigation
2. Headline
3. Subheadline
4. Supporting Text
5. CTA Buttons
6. Hero Image

Animation runs only once.

---

## Scroll Reveal

Each section fades upward when entering the viewport.

Distance:

20–30px

Duration:

500ms

Trigger only once.

---

## Button Interaction

Hover

- Slight background transition
- Slight elevation (2–4px)

Active

- Small scale (0.98)

Transition

250ms

---

## Card Interaction

Hover

- Soft shadow increase
- Slight upward movement (2px)

Never rotate cards.

---

## Image Interaction

Gallery images:

- Slight zoom (1.03)
- Soft overlay

Lightbox:

Fade only.

---

## Navbar

Transparent at top.

Changes to white with blur after scrolling.

Smooth transition.
